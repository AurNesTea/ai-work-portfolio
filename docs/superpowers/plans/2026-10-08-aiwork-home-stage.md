## 目標

登入並選定主代理後，首頁上方是角色與橫向場景，下方是該主代理的互動 CLI。人在下方對焦、派工、同意。派工後角色沿關卡跑。一關要開發與測試都通過才算通關。

## 使用流程

1. 尚未選定主代理時，直接開代理頁。
2. 在代理頁選定一家當主代理。Cursor、Claude、Codex、Gemini 都可以。
3. 回到首頁。該家已登入，下方 CLI 直接進互動畫面。還沒登入，才在這個嵌入畫面裡跑該 CLI 的登入。Gemini 沒有登入狀態指令，選定後直接開 `agy`。
4. 要換主代理：回代理頁改選。關掉目前的終端，改開新的那一家。已經派出去的那一輪不取消。若該輪正等回覆，改在新的 CLI 裡處理，或用核准。
5. 下方 CLI 的工作目錄是選定的專案。對焦、派工、同意都在這裡打。派工仍是呼叫 `aiwork run`。只有 `runs/<id>/` 狀態為執行中，才算派工。
6. 派工後，上方角色開始跑。workflow 的一步是一關。
7. 關掉下方終端不會取消已派出去的那一輪。

## 一關怎麼算

每一步必須寫測試指令。任一步沒寫，這次不開始，現況寫明缺哪一步，不扣命。

開發是這一步的 agent 程序。測試是 runner 在開發結束代碼為 0 之後，於專案目錄執行的那條指令。不採信 agent 自己說測試過了。

| 開發結束代碼 | 測試結束代碼 | 結果 |
|---|---|---|
| 不是 0 | 不跑 | 開發沒做完。扣一條命，出現魔王，把錯誤交回這一步的 agent 再改 |
| 0 | 不是 0 | 開發完成、測試失敗。進入除錯，扣一條命，出現魔王，把測試輸出交回 agent 再改 |
| 0 | 0 | 通關。魔王消失，進入下一關 |

開發結束代碼不是 0，只包括這一步逾時、CLI 當掉、模型不能跑，或該 CLI 以錯誤結束。程式寫錯而 agent 仍以 0 結束，要等測試不是 0 才進入除錯。

未登入、權限不足、輸出含「需要產品決定」、月費額度用完必須改走 pay-as-you-go：暫停。不扣命，不出魔王，角色停在這一關。測試不跑。

## 命與魔王

- 一關開始時的命數是該步 `max_retries + 1`。沒寫 `max_retries` 就是 1。
- 上表前兩列各扣一條。還有命就留在這一關繼續跑，畫面不標失敗。
- 命扣完仍失敗：魔王留下，這一輪狀態為失敗並停止。
- 通關後命數重置。下一關用它自己的 `max_retries` 重新算，不把剩的命帶過去。
- 每次扣命都寫進該次 `runs/<id>/status.json`，至少含這一關的命數上限與剩餘命數。面板不自己猜。
- 三關共用主題裡的同一隻魔王圖。

## 首頁換掉什麼

首頁不再鋪原本的工作頁：沒有 workflow 下拉、執行／繼續／核准／取消、文字現況、這次用量表、紀錄列表。這些進度改由上方關卡、命數與魔王表示。派工、繼續與同意在下方 CLI。

用量的月份表、代理選擇、主題換圖仍在，不刪。它們改從選單進入，不再是首頁上的一排分頁按鈕。

## 選單

漢堡按鈕放在畫面右上角。角色從左往右跑，右上不占第一關，也不壓到下方 CLI。按下後，畫面中央打開半透明選單，背後的場景仍可見。選單項目是代理、用量、主題（2026-10-16 擴充：預留格改為派工頁）。選完或關閉後回到首頁。

## 主題

主題在選單裡。三個欄位：角色、背景、魔王。圖檔選這台電腦上的檔案，存在本機設定，不寫進 workflow，也不放進 repo。沒選圖時用現在的簡易棋子。參考圖只取布局，不用該遊戲的角色或場景。

## 終端

嵌入的是本機 PTY 接到面板的終端，不是把系統命令視窗抓進畫面。瀏覽器 preview 與桌面殼走同一條。互動指令是各家 CLI 自己的互動模式，不是 `aiwork run` 用的單次 `-p`／`exec`／`--print`。（2026-10-16 註：啟動時帶派工規則路徑）

## 不做

- 面板自己跑一套與 workflow 無關的測試。
- 用 agent 的自然語言「同意」代替 `aiwork approve` 或暫停後的處理。
- 同時跑兩輪。進行中、等待、等核准時，新的一輪仍拒絕。
- 把命數留到下一關。
- 把主題圖提交進 repo。
