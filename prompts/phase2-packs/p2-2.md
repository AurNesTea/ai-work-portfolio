# Step P2-2: Machine Profile、目標偵測、Apply／Undo 與 CLI 指令

## 任務目標
實作素材包套用（Apply）、還原（Undo）、機器設定檔（`machine.yaml`），以及 CLI 指令 `aiwork packs`。
撰寫單元測試 `tests/test_packs_apply.py`。

## 規範依據
詳讀 `docs/superpowers/plans/2026-10-16-aiwork-dispatch-and-packs.md` Phase 2「這台電腦設定」、「套用 apply」、「P2-2」章節。

## 實作細節
1. **機器設定檔 (`machine.yaml`)**：
   - 預設位置 `~/.aiwork/machine.yaml`。
   - 欄位：`name` (主機名)、`libraries` (預設 `[~/.aiwork/library]`)、`enabled_packs` (啟用素材包清單)、`scope` (固定 `global`)、`cli_dirs` (自動偵測各 CLI 目錄)。
   - 提供載入、儲存與啟用/停用 pack 的函式。

2. **目標目錄偵測與去重**：
   - 偵測 `~/.agents`, `~/.claude`, `~/.cursor`, `~/.gemini/config`。
   - 若目錄透過 junction / symlink 指向同一個 `realpath`，只寫入一次，避免重複寫入。

3. **套用核心 (`apply_packs(packs, dry_run=True, replace=False)`)**：
   - 預設為 dry-run，回傳計畫摘要（`plans`: 將新增、將取代、衝突、將建立目錄）。
   - **保護 kit 與硬連結**：
     - 若目標檔案已存在且不在 manifest 內，且 `nlink > 1`（硬連結，如 kit 檔）：**永遠拒絕覆寫**，以保護 kit 正本。
     - 目標檔案存在且不在 manifest 內但 `nlink == 1`：必須明示 `replace=True` 且先行備份至 `~/.aiwork/backups/<timestamp>/`。
   - 角色檔：寫入 `~/.agents/agents/<id>.md`。
   - 規則檔：寫入真檔 `~/.agents/rules/<name>.mdc`，並以 `os.link` 建立硬連結至 `~/.agents/rules/<name>.md` 與 `~/.gemini/config/.agents/rules/<name>.md`。
     - 若硬連結失敗（跨磁區或不支援），退回複製並在 manifest 標註 `mode: copy`。
   - 技能檔：目錄遞迴寫入 `~/.agents/skills/<name>/`。
   - 寫入時記錄雜湊至 manifest `applied.json`。中途若有例外，依已寫入項目自動回滾。

4. **還原核心 (`undo_packs()`)**：
   - 讀取 `applied.json`。
   - 比對當前檔案 sha256 與寫入時雜湊：
     - 雜湊相同：安全刪除。
     - 雜湊不同（被手動修改過）：保留檔案，報告 `modified`，絕不強刪。
   - 若有備份檔，從備份目錄完整還原。
   - 清除 manifest 記錄。絕不刪除不在 manifest 中的任何檔案。

5. **CLI 指令整合**：
   - 在 `src/aiwork/cli.py` 新增子指令 `aiwork packs`：
     - `aiwork packs list`: 列出素材庫內的素材包與啟用狀態。
     - `aiwork packs validate <path>`: 驗證指定素材包目錄或 zip。
     - `aiwork packs apply [--dry-run] [--replace]`: 套用已啟用的素材包。
     - `aiwork packs undo`: 還原已套用的素材包。
     - `aiwork packs status`: 顯示這台電腦的啟用素材包、套用狀態、各 CLI 目錄現況。
     - `aiwork packs doctor`: 檢查環境與設定（如 machine.yaml 是否誤入 git repo）。

6. **測試 `tests/test_packs_apply.py`**：
   - 測試 dry-run 計畫產生。
   - 測試真實套用：檔案正確寫入、規則硬連結建立（同 inode 或 copy fallback 標記）、manifest 正確記錄。
   - 測試還原：檔案乾淨還原、備份正確復原、被手改檔案不刪除。
   - 測試保護：既有 `nlink > 1` 檔案絕對被擋且不遭修改。
   - 全程使用假 home fixtures，不得觸碰真實目錄。
